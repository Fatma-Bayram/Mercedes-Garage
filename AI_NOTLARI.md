
# AI Kullanım Notları

## 1. Kullanılan AI Araçları
Proje geliştirme sürecinde ChatGPT kullanılmıştır.

## 2. Kullanılan Promptlar

### Prompt 1
"HTML kullanarak Mercedes araçlarını tanıtan bir web sitesi oluştur."

Amaç: Web sitesinin temel HTML yapısını oluşturmak.

### Prompt 2
"CSS kullanarak Mercedes Garage web sitesini modern ve mobil uyumlu hale getir."

Amaç: Sayfanın tasarımını ve mobil görünümünü düzenlemek.

### Prompt 3
"JavaScript kullanarak araç arama, filtreleme ve temizleme özellikleri ekle."

Amaç: Web sitesine etkileşimli özellikler kazandırmak.

## 3. AI Önerilerinin Değerlendirilmesi

AI tarafından sunulan öneriler proje ihtiyaçlarına göre incelenmiştir.

- Uygun bulunan HTML ve CSS önerileri kullanılmıştır.
- JavaScript önerileri projenin mevcut yapısına göre uyarlanmıştır.
- Gereksiz veya proje kapsamına uymayan öneriler kullanılmamıştır.

## 4. Event Listener Kullanımı

JavaScript içerisinde kullanıcı etkileşimlerini takip etmek için event listener kullanılmıştır.

Örnek:
`addEventListener()`

## 5. Filtreleme Koşulu

Araç arama ve filtreleme işlemlerinde koşullu ifadeler kullanılmıştır.

Örnek:
`if` koşulu ile arama metnine uygun araçlar listelenmiştir.

## 6. Sonuç

AI araçları proje geliştirme sürecinde yardımcı olarak kullanılmış, öneriler kontrol edilerek projeye uyarlanmıştır.
